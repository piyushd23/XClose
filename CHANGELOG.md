# Changelog

All notable changes to XClose are listed here. Each release's section is
shown to users in the update window, so write it for them.

## 1.0.1

- A dot on the menu-bar icon now tells you when an update is ready.
- You get a one-time notification when a new version is available. Click it to see what's new and install.
- Settings › General › Updates shows the waiting version with an **Install** button.

## 1.0.0

- First public release.
- Clicking a window's red × quits the whole app, like ⌘Q. Hold ⌥ Option to close just the window.
- Apps hide instantly while they quit and come back if they ask to save.
- Exclude any app; Finder and system components are always excluded.
- Automatic updates.
